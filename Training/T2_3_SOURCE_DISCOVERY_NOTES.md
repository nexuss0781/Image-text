# T2.3 Source Discovery Notes

**Scope**: Public-documentation review only. No provider account, contract, data download, source-content acquisition, corpus creation, or model training occurred.

| Pathway | Public Evidence Observed | Preliminary Assessment |
| :--- | :--- | :--- |
| Art Institute of Chicago Open Access | The official page presents a public API and states that it offers unrestricted use of more than 50,000 collection images. | Strong candidate for a **narrow, first-party public-domain/open-access pipeline-validation pilot**. It is likely not broad enough by itself for general visual capability and still requires asset-level rights flags, domain-fit review, and a finite manifest. |
| Art Institute of Chicago Open Access Images | The official policy states that images labeled “CC0 Public Domain Designation” may be used for any purpose, including commercial use, free of charge and without additional permission. It also says users remain responsible for identifying any third-party permissions. | A viable **first-party open-access pilot candidate** if an allow-list retains only assets with the CC0 label and captures object-page metadata, rights status, attribution text, source URL, retrieval time, and a safety/privacy review decision. The pilot must not treat the entire site as blanket-cleared. |
| Smithsonian Open Access | The official Open Access page describes developer tools and access to images/data, including a public API. | Candidate for a narrow first-party collection pilot only if every selected asset is explicitly marked CC0 and retained with its item-level rights flag. |
| Smithsonian Terms of Use | The official terms state that content marked with the CC0 icon may be used commercially without copyright restriction, but also say the Smithsonian does not guarantee third-party rights and that privacy/publicity or other rights may apply. Other content is subject to separate usage conditions. | More structured than a general URL index, but still **not blanket-cleared**. A future pilot must filter strictly to CC0-marked assets and keep per-item rights/metadata evidence plus a privacy/safety review. |
| Shutterstock Data Licensing | The official data-licensing page was not textually accessible in the review browser, while its official public description was located through search. | Conditional **commercial permissioned-data pathway**. It may offer better visual diversity and contractual governance but cannot be scored as approved until a written training-use proposal, provider terms, cost, retention, removal, audit, and downstream-use clauses are reviewed. |
| User-owned or commissioned corpus | No external data required; the owner can provide or commission an explicit rights/consent record. | Preferred source class for a domain-specific pilot because permission, scope, retention, and removal can be negotiated directly. It needs a named provider/asset set before it can be evaluated. |
| Synthetic data from a named licensed generator | Search located Adobe’s official generative-AI guidelines, but the accessible browser page did not expose usable text for independent term verification in this review. | Potentially useful for controlled prompts and labels, but **not eligible yet**. A future proposal must attach the exact provider plan/terms at generation time, the output-use grant, prompt/output manifests, policy-screening results, and a documented process for avoiding personal data, protected marks, unsafe material, and misleading labels. |
