# T2.4–T2.5 Training-Pilot Error Cycles

**Purpose**: Preserve the failures, root causes, corrections, and containment decisions encountered while converting the source-discovery work into a runnable controlled pilot.

| Cycle | Failure or constraint | Root cause | Corrective action | Verification and impact |
| :---: | :--- | :--- | :--- | :--- |
| 1 | Metadata-manifest builder stopped with `KeyError: 'id'`. | Candidate records intentionally used `source_artwork_id`, while selection/split functions still referenced the raw API field name. | Replaced stale candidate-record ID references with `source_artwork_id`. | Builder advanced past the failure; no media request was involved. |
| 2 | Initial bounded metadata review contained only 100 records despite a 6,000-record cap. | The provider’s search response did not always expose `next_url`; the script treated its absence as end of pagination. | Used bounded explicit page iteration and maintained the declared maximum review limit. | A 1,000-record review produced a traceable metadata audit; no external image media was requested. |
| 3 | Larger metadata pagination reached provider `HTTP 403` at page 11. | Provider access controls rejected deeper automated search pagination. | Reduced the review to the responsive 1,000-record finite boundary rather than bypassing controls or using an unreviewed mirror. | Manifest construction remained bounded and reproducible. |
| 4 | The 300-record Art Institute target could not be satisfied after conservative exclusions; a 200-record target initially returned 185 records. | The category-balancing selector stopped after sparse selected categories exhausted, even though screened candidates remained. | Retained category-balanced first pass and filled remaining capacity only from already screened candidates in deterministic order. | 200 selected records, 45 classifications, and non-empty 287/41/56-style split logic were verified for the later controlled corpus process. |
| 5 | Manifest audit initially flagged selected candidates as unresolved. | Audit treated the builder’s `candidate` state as an error even when its artwork ID was present in the final allow-list. | Required exact equality between candidate-decision IDs and final manifest IDs. | T2.4 metadata manifest audit passed. |
| 6 | Art Institute IIIF media acquisition stalled and a direct probe returned a Cloudflare `HTTP 403` challenge. | Official delivery endpoint blocked automated image retrieval in the validation environment. | Terminated the process, retained zero source images, did not bypass the access control, and recorded the delivery block. | Selected a project-owned deterministic corpus rather than weakening provenance or rights controls. |
| 7 | Project-owned corpus generator had an invalid module-entry typo before first execution. | A stray character was introduced in the `__main__` guard. | Corrected the entry point before execution and compiled the script. | Generator produced 384 scenes, 384 unique captions, and 384 unique checksums; audit passed. |
| 8 | Initial adapter report’s thresholded F1 could obscure the continuous-output decision behavior. | A fixed threshold would be arbitrary for ridge outputs, while a metric chosen after held-out scoring would leak evaluation information. | Selected the global threshold on development only, froze it for held-out use, and added a field-wise attribute-slot accuracy metric that does not use the threshold. | B1 improved held-out retrieval, F1, field-wise attributes, and spatial-relation accuracy; rerun outputs were identical. |

No corrective action changed the frozen C++ substrate contracts. Post-training CTest confirmed all five native Stage 1–5 evaluation targets passed.
